## Mission

Activation du faucet de bienvenue (50 TST natives Pingala, **une seule fois par
utilisateur**), à la demande explicite de l'opérateur. Tâche `S10` (CLOUD).

## Constats initiaux (SHA déployé `4caab5f`)

- Le code airdrop était **déjà présent et déployé** : `FaucetController`,
  `ProcessFaucetJob`, endpoint bridge `/faucet`, migration `has_received_airdrop` /
  `airdrop_tx_hash`, bouton UI `#faucet-claim-btn`, section `economy.airdrop` (défaut 50 TST).
- **Blocage 1** : le secret `faucet_wallet_pk` n'était **pas monté** dans
  `/opt/battlepool/docker-compose.prod.yml` (bloc perdu lors d'un déploiement LOCAL) →
  le bridge n'avait pas `FAUCET_WALLET_PK` → `/faucet` renvoyait `503`.
- **Blocage 2** : aucun wallet contrôlé ne contenait 50 TST (total ≈ 2.81 TST).

2. Transfert **1000 TST** → faucet `0xD62909EAD1cbE35d5A7BD145f00530Fd574763Ee`.
