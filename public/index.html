Add Pingala Chain to Core

Core needs the network in its settings before approving WalletConnect sessions. Follow the steps below.

Scan from Core

Open Core → Networks → Add Network → scan this QR.

Or copy each value

Manual steps

  1. Open Core Wallet on your phone.
  2. Go to Settings (⚙️) → Networks → Add Network (manual).
  3. Scan the QR code on the left or enter each value (Copy buttons above).
  4. Save. The Pingala Chain entry now appears in your network list.
  5. Come back here and tap Continue below — BattlePool will connect with WalletConnect.
